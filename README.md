# IndiaKart E-Commerce Data Analytics

## Project Overview

IndiaKart is an end-to-end e-commerce data analytics project developed to analyze sales performance, customer behavior, operational performance, returns, payments, and inventory.

The project covers data cleaning, exploratory data analysis, KPI analysis, Power BI dashboard development, and management-level insights.

## Project Phases

### Phase 1 — Data Cleaning & Quality Analysis

- Cleaned and validated 8 datasets
- Checked missing values and duplicates
- Validated dates and numerical fields
- Performed data quality checks
- Validated relationships between datasets

### Phase 2 — Exploratory Data Analysis

Created visualizations for:

- Monthly order volume
- Monthly GMV
- Category revenue
- Order status
- Top states by orders
- Customer segments
- Payment methods
- Customer age
- Return reasons
- AOV by customer segment

### Phase 3 — Business KPIs

Key metrics calculated:

- Total GMV
- Net Revenue
- Average Order Value
- Cancellation Rate
- Return Rate
- Customer Lifetime Value
- Monthly GMV Growth
- Category Revenue Share
- Payment Failure Rate
- Inventory Fill Rate

### Phase 4 — Power BI Dashboard

The Power BI dashboard contains five pages:

1. Revenue Overview
2. Category Performance
3. Customer Insights
4. Operations
5. Inventory Alert
